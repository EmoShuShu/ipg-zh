# 万智牌违规处理方针翻译项目 Magic Infraction Procedure Guide Translation Project

## 主项目说明

本项目维护《万智牌违规处理方针》的中文翻译、注解和网站发布文件。
日常维护以配套的 [MTR 项目](https://github.com/EmoShuShu/mtr-zh) 为基准。

## 历史与原生模型

IPG 保留自己的违规结构、三部分版本标识、稳定 ID、批注及不可变快照。
这些数据不依赖 MTR 仓库；早期阶段命令仅用于复现历史过程。
详见 [对齐前维护记录](docs/review/2026-11-06-before-maintenance-alignment.md)。
